# הגדרת מייל בטלפון

## איזו אפליקציה משתמשים בה למייל בטלפון
בנובה טק קוראים את המייל של העבודה בטלפון רק דרך אפליקציית **Outlook**. אפליקציית המייל המובנית של הטלפון (Mail באייפון, Gmail באנדרואיד) חסומה לחשבונות של החברה, מסיבות אבטחה.
לפני ההגדרה צריך ש-NovaAuth כבר יהיה מוגדר בטלפון.

## הגדרת Outlook בטלפון, שלב אחרי שלב
1. מורידים את Outlook מחנות האפליקציות.
2. פותחים את האפליקציה ומזינים את כתובת המייל במלואה: first.last@nova.co.il.
3. מזינים את הסיסמה הרגילה.
4. מאשרים עם קוד מ-NovaAuth.
5. האפליקציה תבקש לרשום את הטלפון בפורטל אור ← "הטלפון שלי". מאשרים.
אחרי כמה דקות המייל, היומן ואנשי הקשר מסתנכרנים.

## Outlook בטלפון מבקש סיסמה שוב ושוב
זה קורה כמעט תמיד אחרי החלפת סיסמה: Outlook בטלפון עדיין שומר את הסיסמה הישנה.
הפתרון: ב-Outlook בטלפון ← הגדרות ← החשבון ← "הסר חשבון", ואז מוסיפים אותו מחדש עם הסיסמה החדשה.
חשוב לטפל בזה מהר: Outlook שמנסה שוב ושוב עם סיסמה ישנה עלול לגרום לנעילת החשבון.

## המייל בטלפון לא מתעדכן
1. בודקים שיש אינטרנט בטלפון.
2. ב-Outlook מושכים את רשימת המיילים למטה, כדי לרענן.
3. בודקים בהגדרות הטלפון שלאפליקציית Outlook מותר לרוץ ברקע ולהשתמש בנתונים.
4. אם זה לא עוזר, מסירים את החשבון ומוסיפים אותו מחדש.

## איבדתי את הטלפון שהמייל של העבודה מוגדר בו
מודיעים מיד לצוות IT בשלוחה 7700, או במוקד החירום בשלוחה 7799 מחוץ לשעות הפעילות.
צוות IT יכול למחוק מרחוק את נתוני העבודה מהטלפון, בלי לגעת בתמונות ובקבצים האישיים. אחר כך צריך גם להעביר את NovaAuth לטלפון חדש, לפי המדריך "הגדרת אימות דו-שלבי (NovaAuth)".
