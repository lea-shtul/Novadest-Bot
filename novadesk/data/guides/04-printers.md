# מדפסות: חיבור, דרייברים ותקלות נפוצות

## אילו מדפסות יש במשרד
| מדפסת | מיקום | סוג |
|---|---|---|
| HP-2F | קומה 2, ליד המטבחון | שחור-לבן, דו-צדדי |
| HP-3F | קומה 3, ליד חדר ים | שחור-לבן, דו-צדדי |
| צבעונית-1 | קומה 1, ליד הקבלה | צבעונית, דורשת קוד הדפסה |
בדרך כלל כדאי להדפיס במדפסת שבקומה שלך. מדפסת צבעונית-1 מיועדת רק להדפסות שבאמת צריכות צבע.

## חיבור מדפסת למחשב
1. מוודאים שהמחשב מחובר לרשת Nova-Staff במשרד, או ל-NovaConnect מהבית.
2. פותחים את סייר הקבצים ומקלידים בשורת הכתובת: \\nova-files\printers
3. לוחצים לחיצה כפולה על המדפסת הרצויה. הדרייבר יותקן אוטומטית.
4. המדפסת תופיע ברשימת המדפסות בכל תוכנה.

## קוד הדפסה במדפסת צבעונית-1
מדפסת צבעונית-1 לא מדפיסה מיד. ההדפסה ממתינה עד שמזינים קוד אישי במסך המגע של המדפסת.
הקוד האישי מופיע בפורטל אור ← "החשבון שלי" ← "קוד הדפסה". מטרת הקוד היא שמסמכים לא יישארו על המדפסת, ולחסוך בדיו צבעוני.
הדפסה שלא שוחררה בקוד נמחקת אוטומטית אחרי 24 שעות.

## המדפסת מדפיסה דפים ריקים
אם מדפסת HP-2F או HP-3F מוציאה דפים ריקים, הבעיה בדרך כלל לא בטונר אלא בדרייבר. עדכון של Windows מחליף לפעמים את הדרייבר הייעודי בדרייבר גנרי, שלא עובד נכון עם המדפסות שלנו.
הפתרון: מסירים את המדפסת מהגדרות Windows ← "מדפסות וסורקים", ומחברים אותה מחדש דרך \\nova-files\printers.
אם הבעיה חוזרת, יש סקריפט תיקון בתיקייה \\nova-files\drivers. כדאי לפתוח טיקט כדי שצוות IT יריץ אותו.

## נייר תקוע במדפסת
1. פותחים את הדלת הקדמית של המדפסת ומושכים בעדינות את הדף, בכיוון יציאת הנייר.
2. אם לא רואים דף, בודקים גם את מגש 2, המגש התחתון.
3. סוגרים את כל הדלתות. המדפסת תמשיך להדפיס לבד.
אסור למשוך בכוח או להכניס חפצים למדפסת. אם הדף נקרע ונשארו בפנים חתיכות, פותחים טיקט.

## ההדפסה "תקועה" בתור ולא יוצאת
1. בהגדרות Windows ← "מדפסות וסורקים" ← בוחרים במדפסת ← "פתח תור".
2. מבטלים את כל ההדפסות בתור.
3. מפעילים את המחשב מחדש, ושולחים שוב את ההדפסה.
אם התור לא מתרוקן, פותחים טיקט ומציינים את שם המדפסת.

## נגמר הטונר או הנייר
הנייר נמצא בארון שליד כל מדפסת, ומותר לכל עובד להוסיף נייר.
את הטונר מחליף רק צוות IT. כשהמדפסת מציגה "Toner low", פותחים טיקט בפורטל אור, בקטגוריה "מדפסות".
